# Güvenlik Politikası

## Desteklenen sürüm

Şu anda yalnızca en güncel `1.x` sürümü desteklenmektedir.

## Güvenlik açığı bildirimi

Güvenlik açıklarını herkese açık GitHub issue olarak yayımlamayın. Depo sahibiyle özel iletişim kanalı üzerinden aşağıdaki bilgileri paylaşın:

- Etkilenen sürüm
- Yeniden üretme adımları
- Beklenen ve gerçekleşen davranış
- Varsa veri kaybı veya plaintext sızıntısı etkisi

Parola, Master Key, kurtarma anahtarı, gerçek kasa dosyaları veya kullanıcı belgeleri göndermeyin.

## Güvenlik modeli

Administrator hesaplarının dosya varlığını görmesi veya şifreli blobları kopyalaması engellenemez. Güvenlik hedefi, bu blobların doğru parola ya da kurtarma anahtarı olmadan okunamamasıdır.
